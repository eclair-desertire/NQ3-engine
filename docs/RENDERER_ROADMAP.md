# План модернизации рендерера (renderervk)

Цель: современная картинка (PBR, динамический свет с тенями, HDR, AO, объёмный туман) в Vulkan-рендерере Quake3e,
не ломая то, за что ценят id Tech 3: высокий FPS, низкую задержку и совместимость с картами и шейдерами Q3.

Принципы:
- **Каждая возможность включается cvar'ом** и имеет откат к старому пути. Слабые ПК и соревновательные настройки
  должны работать как раньше.
- **Расширяемость важнее скорости внедрения.** Новые данные материалов описываются в shader-скриптах
  (новые ключевые слова), новые проходы рендера — через общий механизм render pass'ов, а не заплатками в `vk.c`.
- **Проверяемость.** У каждого этапа есть тестовая сцена и скриншоты «до/после», снятые скриптом.

## Что уже есть в Quake3e
- Рендер во внешний буфер (`r_fbo`), HDR-буфер с плавающей точкой (`r_hdr`), bloom (`r_bloom*`), MSAA, `r_renderScale`.
- Попиксельные динамические источники (`r_dlightMode 1/2`), без теней.
- Шейдеры GLSL → SPIR-V (`code/renderervk/shaders`, сборка `compile.bat`, нужен `glslangValidator`).
- Модели MD3 и IQM (скелетная анимация), BSP-карты с лайтмапами и lightgrid.

## Этапы

### 0. Инфраструктура
- Сборка шейдеров из скрипта без ручных шагов (glslang в репозитории или скачивается скриптом).
- Скрипт снятия скриншотов тестовых сцен для сравнения «до/после».
- Набор графических пресетов: «соревновательный» (как сейчас) и «качество».

### 1. HDR-конвейер и тонмаппинг
- Освещение считается в линейном пространстве, вывод через тонмаппинг (ACES/AgX) и экспозицию.
- Автоэкспозиция (адаптация глаза), улучшенный bloom (многоуровневый, физичный порог).
- Цветокоррекция через LUT (у каждой карты может быть своя палитра — важно для киберпанк-неона).

### 2. Материалы (PBR)
- Новые ключевые слова в shader-скриптах: `normalMap`, `roughnessMap`/`metallicMap` (или упакованная ORM-карта),
  `emissiveMap` (неон), параметры по умолчанию для старых шейдеров.
- Касательные (tangent space) для BSP, MD3 и IQM — считаются при загрузке.
- Модель освещения Cook-Torrance (GGX) для динамических источников и lightgrid.
- Эмиссия пишется в HDR-буфер и автоматически «светится» через bloom.

### 3. Динамический свет и тени
- Тени от точечных источников (кубические shadow map'ы) с бюджетом на кадр.
- Солнце из `q3map_sun` неба: каскадные тени (CSM).
- Кластерный/тайловый учёт источников (forward+), чтобы держать десятки огней без падения FPS.

### 4. Экранные эффекты и атмосфера
- SSAO / GTAO, контактные тени.
- Объёмный туман и свет (god rays) — ключевая часть киберпанк-атмосферы.
- Отражения: кубические пробы окружения (IBL), затем SSR для мокрых поверхностей.

### 5. Карты и запечённый свет
- HDR-лайтмапы и deluxemaps (направление света) из q3map2, чтобы нормал-мапы работали со статическим светом.
- Пробы освещения для динамических объектов вместо грубого lightgrid.
- Импорт детальной геометрии из Blender в карты (misc_model / IQM).

## Порядок работы
Этапы идут по порядку, но внутри каждого — маленькими шагами с рабочей сборкой после каждого шага.
Текущий статус ведётся в этом файле.
